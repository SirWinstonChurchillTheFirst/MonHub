MonHub for Linux
================

1. Unpack this folder wherever you like (your home folder is fine).
2. Run install.sh once:
     - in the file manager: right click on install.sh -> "Run as a program" (or "Run in terminal")
     - or in a terminal:    ./install.sh
   It unpacks the emulators and puts MonHub into your applications menu.
3. Start MonHub from the applications menu.

Everything stays in this folder: your games go into "ROMs", saves end up in "Spielstände".
ROMs are not included - you need your own.

If you move the folder, run install.sh again (the menu entry points at the folder).
To remove MonHub: run uninstall.sh, then delete the folder (copy your ROMs and saves out first).

What comes with it: melonDS (DS), mGBA (Game Boy, GBA), Azahar (3DS) and a Java runtime for the randomizer.
DeSmuME is Windows-only and not part of the Linux version.

Needs a 64-bit (x86-64) Linux with a desktop. A graphics card with Vulkan or OpenGL 4.3 is needed for 3DS games.
