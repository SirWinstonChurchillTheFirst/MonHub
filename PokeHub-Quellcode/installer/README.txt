MonHub
======

Your game hub: randomizer, emulators for Game Boy, GBA, DS and 3DS
and your fangames – all in one window.

HOW IT WORKS
0. On the first start after installing, Porygon asks whether it should
   show you around – after an update it only shows what's new. The
   tour is always available again under "Options".
1. Start MonHub: desktop icon, Start menu, or just type "MonHub" into
   the Windows search.
2. Menu "Games" -> "Folders & import": open the ROM folder and copy
   your own Pokémon ROMs (.nds, .gba, .gb, .3ds …) into it.
   Or "Import from emulator": brings over ROMs and saves from the
   emulator you used so far (DeSmuME, melonDS, VisualBoyAdvance, mGBA).
   Everything is only copied, your old files stay untouched.
   ROMs are NOT included – you need your own.
3. Menu "New run": pick an original and press "Mix & play" – the game
   is randomized and starts right away in melonDS.
   All of the randomizer's options: "Edit …" there.
4. Later you carry on under "Continue". It shows your last save like
   the game does (trainer, play time, badges, team), and "Continue"
   opens it in the same emulator.
   Don't forget to save in the game itself!
5. Another game? Menu "Games": all games and runs, with search,
   filters and favorites (☆). Each starts in the emulator with your
   newest save; if you pick the other emulator, the save comes along.
   You can also delete a save or a whole game there: "Delete game"
   takes the ROM, saves, savestates, cheats and spoiler along.
   Everything goes to the Recycle Bin.
   Saves without a game are cleaned up there with the Gengar button.
6. Game Boy, Game Boy Color and GBA (Gen 1–3: Red up to Emerald) run in
   mGBA – the same way through "Continue", "Games" and "New run".
   Rare Candy: 99 Rare Candies are in the PC in your room at the start.
7. 3DS (Gen 6–7: X/Y, Omega Ruby/Alpha Sapphire, Sun/Moon,
   Ultra Sun/Ultra Moon) runs in Azahar – also through "Continue",
   "Games" and "New run". Decrypted games only (.3ds, .cci, .cxi).
   A randomized 3DS game is a .cxi file (as big as the original).
   Every game and every run has its own SD card, so its own save.
   Rare Candy: 999 Rare Candies in the first slot of the Medicine
   pocket. If a controller is connected at start, Azahar uses it,
   otherwise the keyboard. 60 FPS is on: smoother, but the game runs
   twice as fast (hold R = normal). Switch it off under "Emulators".
8. "Options": seven looks (Red, Retro, Pink, Neon, Savanna, Spooky,
   Plain), how much may move, the language (English or German) and
   your trainer name.

FOLDERS
Everything is in one folder, usually C:\Users\<Name>\MonHub:
  ROMs\                 your original ROMs
  Randomisierte ROMs\   the randomized games
  Spielstände\          saves of all emulators
  Fangames\             room for fangames (e.g. Gamma Emerald)
  System\               programs and settings – don't touch
(The folder names stay the same in both languages.)

CONTROLS IN MELONDS (also in MonHub under "Emulators")
  Arrow keys = D-pad, X = A, Z = B, S = X, A = Y,
  Q = L, W = R, Enter = Start, Backspace = Select.
  Hold Tab = 4x faster, Space = 2x on/off, F11 = full screen.
  An Xbox controller is set up: L2 = 2x on/off, hold R2 = 4x.
  Your own keys: in melonDS under "Config -> Input and hotkeys".

RARE CANDY CHEAT
  Press L + R in the game (Diamond, Pearl, Platinum, HeartGold,
  SoulSilver) or Select (Black/White 1+2): 999 Rare Candies in the
  Medicine pocket. Works with German and English versions.

UNINSTALLING
  Through Windows "Apps". Your ROMs, saves, randomized ROMs and
  fangames are kept.
